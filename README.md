Glaucoma Detection System 👁️
This is a Deep Learning-based web application that uses a Convolutional Neural Network (CNN) to detect Glaucoma from retinal images. The project is built using TensorFlow/Keras for the model and Flask for the web interface.

🚀 Features
Automated Detection: High-accuracy prediction using a pre-trained .h5 model.

Web Interface: Easy-to-use UI for uploading retinal images and viewing results.

Research Visualizations: Includes ROC curves, confusion matrices, and distribution plots generated during training.

🛠️ Tech Stack
Language: Python

Deep Learning: TensorFlow, Keras

Web Framework: Flask

Image Processing: OpenCV, PIL

Data Science: Pandas, Numpy, Matplotlib
